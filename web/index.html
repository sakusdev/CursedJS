How far can JavaScript
abuse itself?

CursedJS progressively rewrites syntax, values and strings. Each mode adds another layer of structural damage.

cursed

Minification, mangling, string arrays, control-flow flattening and dead code.

Custom Babel AST rewrites attack numbers, booleans, strings and property access first.

03
